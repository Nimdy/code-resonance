# Cymatic Field

A world family for Code Resonance, made with the Visual Pack SDK 1 by **Halcyon Visuals** (a fictional studio: this is the
SDK's reference "outside developer" pack, written only against the SDK documentation).

Every subsystem of your project is a resonant plate in a dark hall. Sand settles on each plate's nodal lines, the
places a standing wave leaves still (Chladni figures):

| Your project | In the hall |
|---|---|
| a subsystem | a plate, struck when it appears |
| a module | a resonator pin and a handful of sand |
| a symbol | a pinch of sand: the figures grow denser as the code grows |
| a dependency between subsystems | a sympathetic bridge carrying a standing wave |
| an agent at work | a tuning fork over the plate it works on, exciting ripples |
| a failing test run | dissonance: the plate's sand scatters, red flicker |
| a passing run | a clear tone: the sand brightens, the rim rings |
| a verified milestone | resonance: a golden halo that stays |
| a commit | a standing wave across the hall |
| nothing happening | the plates slowly morph between modes; the sand keeps dancing to the music |

The recipe draws its parameters from your project: coupled subsystems stand closer, more symbols per module give finer
figures, agent-heavy work makes the sand dance more. Verified milestones unlock golden dust, overtones, an aurora and
distant plates.

Install and approve (it contains code, so it runs in Code Resonance's isolated pack frame only after you allow it):

    node scripts/pack.js install packs/examples/cymatic-field
    node scripts/pack.js approve halcyon.cymatic-field

Then choose **Cymatic Field** among the living worlds in the Visual Studio. MIT licensed.
