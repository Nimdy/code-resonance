# Ember Observatory

A **declarative** visual pack (Visual Pack SDK 1) by Northlight Works, a fictional studio: data only, no code, so it needs
no approval and runs in the player directly. It re-tunes Stellar Forge: a binary core, embers instead of plasma, slow
tilted orbits, probes for agents, a warm film grade (lower saturation, warm tint, lifted shadows, grain, aberration).
Passing tests read as a calm pulse and milestones as an aurora (same polarity as the originals: a failure can never be
mapped to a success effect). Ranges such as `"geometry.spiralArms": [2, 3]` are drawn per project from its seed.

    node scripts/pack.js install packs/examples/ember-observatory

Then choose **EMBER OBSERVATORY · STELLAR-FORGE** under the look selector in the World DNA panel. CC0.
