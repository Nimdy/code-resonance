# Media

The demo reel, its looping preview and the gallery stills. They were cut on 2026-10-27 from the Phase 11 review films:
real renders of the player on an AMD integrated GPU (WSL2), playing the recorded `lumen` session, a real VS Code
session with six AI agents. No event was added or removed. The films themselves are local and not committed
(`qualification/results/films/phase11/`).

| File | What it is |
|---|---|
| `code-resonance-demo.mp4` | A 70 s reel (1280×720, H.264 + AAC). Its parts, in order: Fractal Biosphere, Stellar Forge, Machine Cathedral, music influence 0/1/2, the three finishes, an Artist Studio composition (Aurora Loom), then the Artist Studio and the Music Studio. The soundtrack is one continuous excerpt of Film 1's composed score (Ambient, 160–230 s), laid under every part |
| `preview.webp` | An 8 s loop (900×506, every frame a key frame) of the Biosphere, the Forge, the Cathedral and Aurora Loom |
| `world-*.jpg` | One frame of each flagship world, from a new identity (Cinematic finish, composed score, ecology 2) |
| `finishes.jpg`, `music-influence.jpg` | A frame of each comparison (Film 3 and Film 2) |
| `artist-aurora-loom.jpg` | Aurora Loom, a composition built entirely in the Artist Studio's interface (Film 4) |
| `ui-*.jpg` | Control Center screenshots at 1920×1080, scaled to 1600 px |

Shown names are the Stage's public labels (an agent's role, an event's meaning). No project folder, path or source
appears in any of them.
