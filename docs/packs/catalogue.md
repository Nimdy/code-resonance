# Parameter catalogue (SDK 1.0.0, catalogue 1.0)

Generated by `node scripts/pack.js catalogue` from `engine/catalog.js`: every genome parameter a declarative or shader pack may set on a
built-in family, with its range (every family is rendered with all parameters at their minimum and at their maximum in
`qualification/visual/catalogue.qual.js`). Numbers also accept `[min, max]`: the recipe draws a value per project.

## Effect polarity

An intent may only be expressed by an effect of the same class: a failure never looks like success, a removal never looks like growth.

|---|---|

| `structure.removed` | removal |
| `subsystem.connected` | growth |

| `validation.recovered` | success |
| `refactor.validated` | success |
| `milestone.achieved` | success |
